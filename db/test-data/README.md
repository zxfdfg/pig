# 分销系统测试数据

## 快速使用

```bash
# 导入测试数据（会清空并重新插入）
mysql -u root -p < pig/db/test-data/distribution_test_data.sql
```

## 数据说明

- **8个分销商**（包含 admin，不同等级和状态）
- **9条佣金记录**（admin 的：5条已结算 + 3条待结算 + 1条已取消）
- **6条提现记录**（admin 的：2条待审核 + 1条审核通过 + 2条已打款 + 1条已拒绝）
- **完整的分销关系网络**（3级分销）

## 测试账号

- 用户名: `admin`
- 密码: `admin`

登录后可以直接查看：
- **佣金管理**：9条佣金记录
- **提现管理**：6条提现记录
- **分销商管理**：8个分销商

## 注意事项

- 每次执行脚本会**清空并重新插入**所有测试数据
- admin (user_id=1) 已设置为顶级分销商
- 所有数据都是模拟数据，仅用于测试
