# 商品管理系统测试指南

## 📋 测试前准备

### 1. 数据库初始化

```bash
# 进入数据库目录
cd pig/db

# 初始化数据库（会删除并重建数据库）
mysql -u root -p < pig.sql
mysql -u root -p < pig_config.sql

# 导入测试数据
mysql -u root -p < test-data/test_data.sql
```

### 2. 启动后端服务

按以下顺序启动服务：

```bash
# 1. 启动 Nacos 注册中心 (8848)
cd pig/pig-register
mvn spring-boot:run

# 2. 启动网关服务 (9999)
cd pig/pig-gateway
mvn spring-boot:run

# 3. 启动认证服务 (3000)
cd pig/pig-auth
mvn spring-boot:run

# 4. 启动用户权限管理服务 (4000)
cd pig/pig-upms/pig-upms-biz
mvn spring-boot:run

# 5. 启动商品管理服务 (4200)
cd pig/pig-product/pig-product-biz
mvn spring-boot:run
```

### 3. 启动前端

```bash
cd pig-ui
npm run dev
```

访问: http://localhost:8888

默认账号: admin / admin

## 🔍 API接口测试

### 使用Postman或curl测试

#### 1. 获取Token

```bash
curl -X POST "http://localhost:9999/auth/oauth2/token" \
  -H "Authorization: Basic cGlnOnBpZw==" \
  -d "grant_type=password&username=admin&password=admin"
```

#### 2. 测试商品接口

```bash
# 查询商品列表
curl -X GET "http://localhost:9999/product/product/page?current=1&size=10" \
  -H "Authorization: Bearer {token}"

# 创建商品
curl -X POST "http://localhost:9999/product/product" \
  -H "Authorization: Bearer {token}" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "测试商品",
    "categoryId": 1,
    "type": 0,
    "price": 99.99,
    "stock": 100
  }'

# 更新商品状态
curl -X PUT "http://localhost:9999/product/product/status/1?status=1" \
  -H "Authorization: Bearer {token}"
```

#### 3. 测试分类接口

```bash
# 查询分类树
curl -X GET "http://localhost:9999/product/category/tree" \
  -H "Authorization: Bearer {token}"
```

## 🐛 常见问题排查

### 1. 菜单不显示

**问题**: 登录后看不到"商品管理"菜单

**解决方案**:
```sql
-- 检查菜单是否存在
SELECT * FROM sys_menu WHERE menu_id = 4000;

-- 检查角色菜单关联
SELECT * FROM sys_role_menu WHERE menu_id = 4000;

-- 如果没有，执行以下SQL
INSERT INTO sys_role_menu VALUES (1, 4000);
-- ... 添加所有子菜单权限
```

### 2. 服务无法启动

**问题**: 商品服务启动失败

**排查步骤**:
1. 检查Nacos是否正常运行（访问 http://localhost:8848/nacos）
2. 检查数据库连接配置是否正确
3. 检查端口4200是否被占用
4. 查看服务日志，定位具体错误

### 3. 网关路由不通

**问题**: 前端调用接口404

**排查步骤**:
1. 检查网关服务是否正常运行
2. 检查Nacos配置中心的网关配置是否包含product路由
3. 检查商品服务是否已注册到Nacos
4. 使用浏览器开发者工具查看实际请求URL

### 4. 前端页面报错

**问题**: 前端页面显示错误或功能异常

**排查步骤**:
1. 打开浏览器开发者工具，查看Console错误
2. 检查Network标签，查看API请求是否成功
3. 检查API返回的错误信息
4. 验证前端路由配置是否正确
