# 分销系统 V2.0 新增功能清单

## 📋 概述

本文档列出了分销系统 V2.0 版本新增的所有功能，这些功能基于成本控制和业务优化的需求而设计。

---

## 🎯 核心价值

### 对供应商的价值

1. **成本可控**: 实时监控佣金成本，确保盈利
2. **决策支持**: 提供利润计算和模拟工具，辅助定价决策
3. **自动化管理**: 减少人工操作，提升管理效率
4. **风险防控**: 防止刷单和异常提现，保护平台利益

### 对分销商的价值

1. **自动升级**: 根据业绩自动升级，激励更强
2. **推广便利**: 专属推广工具，提升转化率
3. **数据透明**: 详细的数据报表，了解团队情况
4. **及时通知**: 重要消息实时推送，不错过机会

---

## 🆕 新增功能列表

### 1. 成本控制与利润监控

#### 1.1 佣金成本实时监控 ⭐⭐⭐⭐⭐

**功能描述**:
- 在订单详情页显示该订单的佣金成本
- 显示佣金成本占订单金额的百分比
- 佣金率超过阈值时显示预警标识

**使用场景**:
```
供应商查看订单详情时，可以立即看到：
- 订单金额：1000元
- 佣金成本：300元（30%）⚠️ 超标
- 供应商利润：200元（20%）
```

**业务价值**:
- 实时了解每笔订单的佣金成本
- 及时发现高成本订单
- 辅助定价决策

---

#### 1.2 利润率计算器 ⭐⭐⭐⭐⭐

**功能描述**:
- 输入产品成本和售价，自动计算毛利率
- 模拟不同分销场景（一级/二级/三级）的利润
- 显示不同分销商等级下的佣金成本
- 显示最终供应商利润和利润率

**使用场景**:
```
供应商在定价前使用计算器：

输入：
- 产品成本：500元
- 售价：1000元

输出：
- 毛利率：50%

场景模拟：
┌─────────────┬──────┬──────┬──────┬──────┐
│ 场景        │ 佣金 │ 成本 │ 利润 │ 利率 │
├─────────────┼──────┼──────┼──────┼──────┤
│ 一级-普通   │  80  │ 500  │ 420  │ 42%  │
│ 一级-钻石   │ 180  │ 500  │ 320  │ 32%  │
│ 三级-钻石   │ 300  │ 500  │ 200  │ 20%  │
└─────────────┴──────┴──────┴──────┴──────┘

结论：售价1000元可以确保盈利 ✅
```

**业务价值**:
- 快速评估定价是否合理
- 了解不同场景下的利润空间
- 避免亏本销售

---

#### 1.3 佣金配置模拟器 ⭐⭐⭐⭐

**功能描述**:
- 调整佣金比例，实时显示对利润的影响
- 支持批量调整某个层级或等级的佣金比例
- 显示调整前后的对比数据
- 支持保存模拟方案并应用到实际配置

**使用场景**:
```
供应商想提高一级佣金来激励分销商：

当前配置：
- 一级-钻石：18%
- 二级-钻石：8%
- 三级-钻石：4%
- 总成本：30%

调整方案：
- 一级-钻石：20% ↑
- 二级-钻石：8%
- 三级-钻石：4%
- 总成本：32%

影响分析：
- 利润率从 20% 降至 18%
- 预计销量提升 15%
- 综合收益提升 10%

决策：应用此方案 ✅
```

**业务价值**:
- 科学调整佣金配置
- 评估调整的影响
- 优化佣金策略

---

#### 1.4 成本预警机制 ⭐⭐⭐⭐

**功能描述**:
- 每日统计平均佣金率
- 佣金率超过阈值时发送预警通知
- 统计高佣金订单数量和占比
- 提供成本异常订单列表

**使用场景**:
```
系统每日 9:00 发送成本报告：

📊 昨日成本分析
- 平均佣金率：28% ⚠️ 接近上限
- 高佣金订单：15笔（占比 12%）
- 建议：考虑调整佣金配置

异常订单：
- 订单 #12345：佣金率 35% ❌
- 订单 #12346：佣金率 32% ⚠️
```

**业务价值**:
- 及时发现成本异常
- 防止成本失控
- 辅助决策调整

---

- 提供日/周/月利润报表

```
│ ...  │  ...   │ ...  │ ...  │ ...  │ ...  │
```

- 全面了解盈利情况
- 发现利润趋势
- 辅助经营决策

### 2. 分销商等级自动升级

#### 2.1 升级条件配置 ⭐⭐⭐⭐

**功能描述**:
- 为每个等级配置升级条件
- 升级条件包含：累计销售额、团队人数、直推人数
- 支持配置多个条件的组合关系（且/或）
- 可以启用或禁用自动升级功能

**使用场景**:
```
配置钻石分销商升级条件：

条件组合：同时满足以下条件
- 累计销售额 ≥ 100万
- 团队人数 ≥ 100人
- 直推人数 ≥ 20人

或者：
- 累计销售额 ≥ 200万
```

**业务价值**:
- 激励分销商提升业绩
- 自动化等级管理
- 减少人工操作

---

#### 2.2 自动升级检测 ⭐⭐⭐⭐

**功能描述**:
- 系统每日检测符合升级条件的分销商
- 自动将符合条件的分销商升级
- 记录升级时间和升级原因
- 发送升级通知给分销商

**使用场景**:
```
系统每日 00:00 执行升级检测：

检测结果：
- 李雨婷：累计销售额 105万 ✅
- 李雨婷：团队人数 120人 ✅
- 李雨婷：直推人数 25人 ✅

操作：李雨婷 金牌 → 钻石 ⬆️

通知：
🎉 恭喜您升级为钻石分销商！
- 一级佣金：15% → 18%
- 二级佣金：6% → 8%
- 三级佣金：3% → 4%
```

**业务价值**:
- 及时奖励优秀分销商
- 提升分销商积极性
- 减少人工审核工作

### 3. 推广工具

#### 3.1 专属推广链接 ⭐⭐⭐⭐⭐

**功能描述**:
- 为每个分销商生成唯一的推广链接
- 推广链接包含分销商ID
- 用户通过推广链接注册后自动建立推荐关系
- 统计推广链接的访问量和转化率

**使用场景**:
```
分销商获取推广链接：

专属链接：
https://shop.com/register?ref=D12345

推广数据：
- 今日访问：156次
- 今日注册：12人
- 转化率：7.7%
- 累计推广：328人
```

**业务价值**:
- 简化推广流程
- 自动建立推荐关系
- 数据可追溯

---

#### 3.2 推广二维码 ⭐⭐⭐⭐

**功能描述**:
- 为每个分销商生成专属二维码
- 二维码包含分销商信息和推广链接
- 支持下载二维码图片
- 二维码支持自定义样式（颜色、Logo）

**使用场景**:
```
分销商下载推广二维码：

[二维码图片]
扫码注册，成为我的下级

样式选择：
- 颜色：蓝色/红色/绿色
- Logo：显示/隐藏
- 尺寸：小/中/大
```

**业务价值**:
- 适合线下推广
- 提升推广效率
- 品牌形象统一

---

#### 3.3 推广素材库 ⭐⭐⭐

**功能描述**:
- 提供产品推广图片和文案
- 分销商可以一键复制推广文案
- 分销商可以下载推广图片
- 管理员可以上传和管理素材

**使用场景**:
```
分销商选择推广素材：

产品A推广素材：
- 图片：3张（点击下载）
- 文案：
  "🔥 限时特惠！原价999，现价699！
   点击链接立即购买 👉 [推广链接]"
  [一键复制]

- 短视频：1个（点击下载）
```

**业务价值**:
- 降低推广门槛
- 统一推广内容
- 提升推广质量

### 5. 消息通知

#### 5.1 佣金到账通知 ⭐⭐⭐⭐⭐

**功能描述**:
- 分销商获得佣金时发送通知
- 通知包含：订单号、佣金金额、当前余额
- 支持站内信、短信、邮件多种方式
- 用户可以在设置中选择通知方式

**使用场景**:
```
分销商收到通知：

💰 佣金到账通知
- 订单号：#12345
- 佣金金额：+120.00元
- 当前余额：1,580.00元
- 时间：2025-12-07 14:30

[查看详情]
```

**业务价值**:
- 及时告知收益
- 提升用户体验
- 增强信任感

---

#### 5.2 提现审核通知 ⭐⭐⭐⭐

**功能描述**:
- 提现申请提交后发送确认通知
- 提现审核通过/拒绝后发送结果通知
- 提现打款完成后发送到账通知
- 通知包含提现金额、手续费、实际到账金额

**使用场景**:
```
提现流程通知：

1️⃣ 提交申请：
"您的提现申请已提交，请等待审核"

2️⃣ 审核通过：
"您的提现申请已通过审核，预计3个工作日到账"

3️⃣ 打款完成：
"💸 提现到账通知
- 提现金额：1,000.00元
- 手续费：10.00元
- 实际到账：990.00元"
```

**业务价值**:
- 提升透明度
- 减少咨询量
- 提升满意度

### 6. 产品分类佣金管理

#### 6.1 产品分类管理 ⭐⭐⭐

**功能描述**:
- 支持创建产品分类
- 每个分类有名称、描述、毛利率范围
- 支持多级分类（最多3级）
- 为分类设置默认佣金配置

**使用场景**:
```
创建产品分类：

分类结构：
├── 电子产品（毛利率 40-50%）
│   ├── 手机（毛利率 45%）
│   └── 电脑（毛利率 40%）
├── 服装（毛利率 50-60%）
│   ├── 男装（毛利率 55%）
│   └── 女装（毛利率 60%）
└── 食品（毛利率 20-30%）
    ├── 零食（毛利率 30%）
    └── 饮料（毛利率 25%）
```

**业务价值**:
- 精细化管理
- 差异化定价
- 成本可控

---

#### 6.2 分类佣金配置 ⭐⭐⭐⭐

**功能描述**:
- 为每个产品分类配置独立的佣金比例
- 高毛利产品设置较高的佣金比例
- 低毛利产品设置较低的佣金比例
- 支持批量调整某个分类的佣金配置

**使用场景**:
```
配置分类佣金：

服装类（高毛利 60%）：
- 一级佣金：20%
- 二级佣金：10%
- 三级佣金：5%
- 总佣金：35%
- 供应商利润：25% ✅

食品类（低毛利 25%）：
- 一级佣金：10%
- 二级佣金：5%
- 三级佣金：2%
- 总佣金：17%
- 供应商利润：8% ✅
```

**业务价值**:
- 灵活控制成本
- 最大化利润
- 激励推广高毛利产品

### 7. 风控机制

#### 7.1 刷单检测 ⭐⭐⭐⭐

**功能描述**:
- 检测异常高频订单
- 检测同一买家多次购买同一商品
- 检测短时间内大量订单
- 检测到异常时暂停佣金结算并发送预警

**使用场景**:
```
系统检测到异常：

⚠️ 刷单预警
- 分销商：李雨婷
- 异常行为：1小时内产生20笔订单
- 买家：同一用户重复购买
- 处理：暂停佣金结算，待人工审核

[查看详情] [人工审核]
```

**业务价值**:
- 防止刷单
- 保护平台利益
- 维护公平竞争

---

#### 7.2 异常提现检测 ⭐⭐⭐⭐

- 检测到异常时标记为待人工审核

**使用场景**:

```
系统检测到异常：

- 历史：无历史订单记录
- 处理：标记为高风险，需人工审核

[查看详情] [人工审核]
```

**业务价值**:
- 防止欺诈
- 降低风险
- 保护资金安全
